Islands of Wakfu recompilé — WakfuRecomp pour Linux

1. Extraire l'archive :  tar -xf WakfuRecomp-linux.tar.zst   (crée le dossier WakfuRecomp)
2. Lancer :              WakfuRecomp/WakfuRecomp            (double-clic dans le gestionnaire de fichiers)
   La fenêtre guide les étapes : Jeu (paquet STFS du jeu, ou image ISO/XISO, ou dossier ; et la Title Update 2),
   Installation (préparation, recompilation et compilation : de quelques minutes à une heure), puis Jouer.
   Composants manquants (clang, cmake, ninja, SDL2, Vulkan, glslang, FFmpeg) : bouton « Installer » sous
   CachyOS / Arch (pacman, mot de passe administrateur demandé) ; autre distribution : la liste est affichée.
3. Ensuite :             « WakfuRecomp » dans le menu des applications (créé au premier lancement).

Dossier : ~/.local/share/wakfu-recomp (jeu, sauvegardes et réglages dans userdata, journaux).
Ancien mode portable (wakfu-recomp à côté du lanceur) : sauvegardes copiées une fois dans le dossier ci-dessus.
Désinstaller : bouton « Désinstaller » de la fenêtre (sauvegardes gardées sauf demande ; le lanceur n'est pas touché).
Aucun fichier du jeu n'est fourni : il faut posséder le jeu et sa mise à jour.
Anticrénelage MSAA (Réglages > Image) : « Auto » le coupe sur GPU intégré (portable) pour gagner en fluidité ;
« Activé » ou « Désactivé » imposent le choix. Le GPU détecté est noté dans journal-lanceur.txt (lignes [gpu]).
Journaux : userdata/journal.log (jeu, lancement en cours ; journal.1.log, journal.2.log avant), journal-lanceur.txt,
userdata/journal-installation.log (lancement par RecompLauncher).
