Islands of Wakfu recompilé — installation sous Linux (CachyOS / Arch)

1. Extraire l'archive :  tar -xf WakfuRecomp-linux.tar.zst   (crée le dossier wakfu-recomp)
2. Lancer :              wakfu-recomp/installer.sh <jeu> <mise à jour>
   <jeu>          : le paquet STFS du jeu (ou image ISO/XISO, ou dossier du jeu)
   <mise à jour>  : le paquet de la Title Update 2
   Le script installe les paquets manquants avec pacman (mot de passe sudo demandé), puis prépare le jeu,
   le recompile et le compile (plusieurs minutes). Journal : ~/.local/share/wakfu-recomp/installation.log
3. Jouer :               ~/.local/share/wakfu-recomp/jouer.sh   (ou « Islands of Wakfu (recompilé) » dans le menu)

Options : --dossier <D> (autre dossier d'installation), --sans-pacman (dépendances déjà installées).
Relancer installer.sh sans argument recompile sans re-préparer le jeu.
Aucun fichier du jeu n'est fourni : il faut posséder le jeu et sa mise à jour.
Réglages : userdata/config.toml (même format que la version Windows).
Journaux : ~/.local/share/wakfu-recomp/userdata/journal.txt (lancement en cours ; journal.1.txt, journal.2.txt avant).
Mesure du GPU (pour améliorer les performances) : lancer
    WAKFU_GPU_PROFIL=1 ~/.local/share/wakfu-recomp/jouer.sh
jouer 2-3 minutes en jeu, quitter, puis envoyer userdata/journal.txt (lignes [rendu ...], [gpu ...], img/s).
