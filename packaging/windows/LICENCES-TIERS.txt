WakfuRecomp.exe - composants tiers inclus
==========================================

Cet installateur ne contient AUCUN fichier du jeu Islands of Wakfu ni code dérivé du jeu : le jeu
(votre copie), le C++ recompilé et wakfu.exe sont produits sur votre machine. Textes complets des
licences : dossier licences/ à côté de ce fichier (outils-<id>/licences dans le dossier d'installation).

du dépôt, options de FFmpeg ci-dessous). La liaison est statique, mais la reliaison avec une autre version est
possible puisque l'installateur compile wakfu.exe sur votre machine à partir des sources du runtime, des
bibliothèques fournies dans deps/ et du script de construction : remplacer deps/ffmpeg suffit.
